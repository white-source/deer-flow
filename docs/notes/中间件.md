---
  中间件全景图（21 个）
  
  分为两层：8 个基础中间件（所有 agent 共用）+ 13 个 Lead Agent 专属。

  基础层 — 没有它们，agent 跑不起来

  _build_runtime_middlewares() 构建

  ┌─────┬─────────────────────────────┬─────────────────────────────────────────────────────┬──────────────────────────────────────────────┐
  │  #  │           中间件            │                      解决问题                       │                  不用会怎样                  │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 1   │ ThreadDataMiddleware        │ 为每个线程创建隔离的文件目录 (threads/<id>/)        │ sandbox 工具找不到工作目录，文件操作全部失败 │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 2   │ UploadsMiddleware           │ 将用户上传的文件路径注入到 HumanMessage 中          │ agent 不知道用户传了什么文件                 │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 3   │ SandboxMiddleware           │ 管理 Docker/本地沙箱生命周期，切换工作目录          │ bash、read_file 等工具无法在隔离环境执行     │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 4   │ DanglingToolCallMiddleware  │ LLM 输出的 tool_call 因框架异常丢失结果时，自动重试 │ 对话卡死，用户看到 "thinking..." 永远不结束  │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 5   │ LLMErrorHandlingMiddleware  │ LLM API 调用失败（超时/限流/500）时自动重试         │ 一次网络抖动就导致整个对话失败               │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 6   │ GuardrailMiddleware         │ 输入/输出安全审查（敏感词过滤等）                   │ 没有内容安全保护                             │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 7   │ SandboxAuditMiddleware      │ 记录沙箱中执行的命令（审计日志）                    │ 无法追溯 agent 执行了什么危险操作            │
  ├─────┼─────────────────────────────┼─────────────────────────────────────────────────────┼──────────────────────────────────────────────┤
  │ 8   │ ToolErrorHandlingMiddleware │ 工具执行报错时格式化错误消息反馈给 LLM              │ 工具报错直接抛异常，agent 崩溃               │
  └─────┴─────────────────────────────┴─────────────────────────────────────────────────────┴──────────────────────────────────────────────┘

  Lead Agent 层 — 没有它们，用户体验会很差
